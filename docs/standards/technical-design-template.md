# 技术方案模板

使用前先按 [文档归属规则](../README.md#修改前先确定归属) 查找所属功能。已有设计时修改原文档；仅在没有合理归属或缺少设计侧时使用本模板，不为每次修复复制一份。

按本次范围填写必要章节，不适用项可注明原因或省略；不得省略关联需求、关键决定、影响范围、错误处理与验证方式。涉及 API 时明确请求、响应、鉴权和兼容性。实施前需获得用户确认。
