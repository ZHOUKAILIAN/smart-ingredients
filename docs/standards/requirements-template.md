# 需求文档模板

使用前先按 [文档归属规则](../README.md#修改前先确定归属) 查找所属功能。已有需求时修改原文档；仅在没有合理归属或缺少需求侧时使用本模板，不为每次修复复制一份。

按本次范围填写必要章节，不适用项可注明原因或省略；不得省略目标、范围、验收标准与关联设计。旧文档已清理，不据此批量补建。

## 元数据

| 字段 | 值 |
|------|-----|
| 文档编号 | [NNN-feature-name；检查编号与路径冲突] |
| 标题 | [功能/组件名称] 需求文档 |
| 所属功能 / 用户旅程 | [稳定归属，不以本次任务编号代替] |
| 关联设计 | [仓库内完整路径，并添加相对链接] |
| 版本 | 1.0 |
| 文档状态 | 草稿 / 已批准 / 已废弃 |
| 批准依据 | [确认人、日期、对应版本及可追溯依据；未确认填待确认] |
| 替代关系 | [无，或替代/被替代文档的完整路径及相对链接] |
| 创建日期 | YYYY-MM-DD |
| 更新日期 | YYYY-MM-DD |
| 作者 | [作者姓名] |
